# Chef Menu Management System

## Project Description
The Chef Menu Management System is an application designed to help chefs manage restaurant menu items efficiently.

The system allows users to add, view, edit, delete, search and filter menu items.

## Project Structure

The project contains two applications:

1. Website
2. Mobile Application

## Website Technologies
- HTML
- CSS
- JavaScript

## Mobile Application Technologies
- React Native
- Expo
- JavaScript
- AsyncStorage

## Main Features

### Menu Management
- Add new menu items.
- View existing menu items.
- Edit menu item details.
- Delete menu items.

### Search and Filtering
- Search menu items by name or description.
- Filter menu items by course.
- Filter options include Starter, Main Course, Dessert and Drink.

### Menu Statistics
- Display the total number of menu items.
- Calculate the average price of all menu items.
- Display the number of items available in each course.

### Validation and User Feedback
- Validate required fields.
- Ensure prices are greater than zero.
- Display success messages.
- Display error messages.
- Confirm before deleting menu items.

## How to Run the Website

1. Open the website folder.
2. Open index.html in a web browser.
3. The website is ready to use.

## How to Run the Mobile Application

1. Install Node.js.
2. Open the mobile-app folder in Visual Studio Code.
3. Open the terminal.
4. Run:

npm install

5. Start the application:

npx expo start

6. Open the application using Expo Go or an Android emulator.

## Data Storage

The website uses browser localStorage to save menu items.

The mobile application uses AsyncStorage to save menu items on the device.

## Conclusion

The Chef Menu Management System provides a simple and user-friendly way to manage restaurant menus. The website and mobile application include menu management, searching, filtering, validation and statistical features.
